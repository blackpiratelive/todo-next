### Core Architecture & Tech Stack
* **Language:** Kotlin

* **Architecture:** MVVM (Model-View-ViewModel)
* **Local Storage:** Room Database (Offline-first architecture)
* **Network & Sync:** OkHttp/Retrofit. The app must implement a background CalDAV client to synchronize `VTODO` items with a Nextcloud Tasks server.
* **Asynchrony:** Coroutines and Kotlin Flow

### Design Language: Modern "Planify" Aesthetic
The UI must feel like a first-class modern application: fluid, beautifully spaced, and highly polished. It must fully support both Light and Dark modes using Material 3 dynamic theming principles.
* **Colors (Dark Mode):** Deep, elegant charcoal (`#1E1E1E` for surfaces, `#25252D` for drawer/backgrounds). White/off-white typography.
* **Colors (Light Mode):** Clean white surfaces (`#FFFFFF`), very light gray backgrounds (`#F5F5F5`). Dark, highly legible typography.
* **Accent Color:** A vibrant, recognizable blue (e.g., `#3584E4`) used for active states, the Floating Action Button (FAB), and primary icons.
* **Shapes & Elevation:** Use heavily rounded corners (e.g., `12dp` to `16dp`) for active drawer items, dialogs, and task rows. Use subtle elevation/shadows in Light Mode to separate overlapping surfaces (like the Top Bar or FAB); keep Dark Mode flat with color boundaries.

### Animation & Interaction Specifications
The app must not feel static. Implement the following Compose animations:
1. **List Animations:** Use `animateItemPlacement()` on the `LazyColumn` so tasks smoothly slide into place when sorting changes.
2. **Task Enter/Exit:** Wrap task rows in `AnimatedVisibility` (using `fadeIn` + `expandVertically` for appearing, and `fadeOut` + `shrinkVertically` for completion/deletion).
3. **State Changes:** Use `animateColorAsState` for the circular checkbox when transitioning from empty to checked.
4. **Navigation:** Smooth drawer open/close transitions.
